# 2026_Utaipei_Geophysics_0909-main

## 東非大裂谷 3D 地形模型

新增互動式 East African Rift 3D Terrain 頁面：

- east-african-rift-3d.html
- Three.js WebGL 3D 地形
- 以高原、裂谷低地、裂谷肩與火山錐建立概念性高程模型
- 可拖曳旋轉、滾輪縮放、右鍵平移
- 可切換網格模式與地形垂直誇張 ×2
- 具有高程色帶與地形標示

> 注意：此版本是依東非大裂谷地貌特徵建立的「概念性／教學型」3D DEM，不是直接載入真實衛星 DEM，因此適合課堂展示地形高低變化與裂谷構造概念。
